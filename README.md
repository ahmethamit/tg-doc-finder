# TG Doc Finder

Telegram gruplarında doküman arayıp bulunan dosyayı iPhone'un paylaş menüsüyle
Gmail'e gönderen, sunucusuz iPhone web uygulaması.

- Mimari: [ARCHITECTURE.md](ARCHITECTURE.md)
- Durum: mimari hazır, geliştirme Faz 0'dan başlayacak.

## iPhone'a kurulum (Faz 0 sonrası)

1. Safari'de `https://ahmethamit.github.io/tg-doc-finder/` adresini aç.
2. Paylaş → **Ana Ekrana Ekle**.
3. Uygulamayı **ana ekrandaki simgeden** aç (Safari'den değil; giriş bilgileri
   ana ekran uygulamasında ayrı saklanır).
4. İlk açılışta [my.telegram.org](https://my.telegram.org) → API development
   tools'tan aldığın **API ID** ve **API Hash**'i gir, sonra telefon numaranla
   giriş yap.
